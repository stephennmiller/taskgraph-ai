TaskGraph is built for Claude Code. Before you start you need two things.

## 1. Claude Code

Install [Claude Code](https://docs.claude.com/en/docs/claude-code) and sign in by running `claude` once. Every AI call TaskGraph makes runs through your signed-in Claude Code, so there are no provider accounts or API keys to set up.

<Tip>
If you would rather bill a specific Anthropic API key, set the optional `CLAUDE_CODE_API_KEY` environment variable. See [Authentication](/getting-started/api-keys).
</Tip>

## 2. Node.js

TaskGraph requires Node.js 22.13 or later. npm comes bundled with Node.js.

<Accordion title="Install Node.js">

**Option 1: Download from the official website**
1. Visit [nodejs.org](https://nodejs.org)
2. Download the **LTS (Long Term Support)** version for your operating system
3. Run the installer and follow the setup wizard

**Option 2: Use a package manager**

<CodeGroup>

```bash macOS (Homebrew)
brew install node
```

```bash Windows (winget)
winget install OpenJS.NodeJS
```

</CodeGroup>

</Accordion>
