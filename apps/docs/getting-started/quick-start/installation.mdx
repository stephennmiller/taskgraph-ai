Now that you have Node.js and your first API Key, you are ready to begin installing TaskGraph in one of two ways. 

<Accordion title="Claude Code Quick Install">

For Claude Code users:

```bash
claude mcp add taskgraph-ai -- npx -y taskgraph-ai
```

Don't forget to add your API keys to the configuration:
- in the root .env of your Project
- in the "env" section of your mcp config for taskgraph-ai

</Accordion>
## Installation Options


<Accordion title="Option 1: MCP (Recommended)">

MCP (Model Context Protocol) lets you run TaskGraph directly from Claude Code.

## 1. Add TaskGraph to Claude Code

Register the server with `claude mcp add` (see Quick Install above), or add it to your project's `.mcp.json`. `taskgraph init --rules claude` writes this file for you.

## Manual Configuration

```json
{
  "mcpServers": {
    "taskgraph-ai": {
      "command": "npx",
      "args": ["-y", "taskgraph-ai"],
      "env": {
        "ANTHROPIC_API_KEY": "YOUR_ANTHROPIC_API_KEY_HERE",
        "PERPLEXITY_API_KEY": "YOUR_PERPLEXITY_API_KEY_HERE",
        "OPENAI_API_KEY": "YOUR_OPENAI_KEY_HERE",
        "GOOGLE_API_KEY": "YOUR_GOOGLE_KEY_HERE",
        "MISTRAL_API_KEY": "YOUR_MISTRAL_KEY_HERE",
        "OPENROUTER_API_KEY": "YOUR_OPENROUTER_KEY_HERE",
        "XAI_API_KEY": "YOUR_XAI_KEY_HERE",
        "AZURE_OPENAI_API_KEY": "YOUR_AZURE_KEY_HERE",
        "OLLAMA_API_KEY": "YOUR_OLLAMA_API_KEY_HERE"
      }
    }
  }
}
```

> 🔑 Replace `YOUR_…_KEY_HERE` with your real API keys. You can remove keys you don't use.

> **Note**: If you see `0 tools enabled` in the MCP settings, restart Claude Code and check that your API keys are correctly configured.

#### 2. (Optional) Configure the models you want to use

In Claude Code, say:

```txt
Change the main, research and fallback models to <model_name>, <model_name> and <model_name> respectively.
```

For example, to use Claude Code (no API key required):
```txt
Change the main model to claude-code/sonnet
```

#### 3. Initialize TaskGraph

In Claude Code, say:

```txt
Initialize taskgraph in my project
```

</Accordion>

<Accordion title="Option 2: Using Command Line">

## CLI Installation

```bash
# Install globally
npm install -g taskgraph-ai

# OR install locally within your project
npm install taskgraph-ai
```

## Initialize a new project

```bash
# If installed globally
taskgraph init

# If installed locally
npx taskgraph init

# Set up the Claude Code integration (CLAUDE.md import, .mcp.json, slash commands)
taskgraph init --rules claude
```

This will prompt you for project details and set up a new project with the necessary files and structure.
</Accordion>
