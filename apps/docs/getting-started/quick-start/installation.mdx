With Claude Code and Node.js in place, install TaskGraph and set it up in your project.

## 1. Install the CLI

```bash
npm install -g taskgraph-ai
```

This gives you the `taskgraph` command and `taskgraph-mcp`, the optional MCP server. To skip the install, run any command through npx, for example `npx -y -p taskgraph-ai taskgraph list`.

## 2. Initialize your project

From your project folder:

```bash
taskgraph init
```

This creates `.taskgraph/` (tasks, docs, config), and a `CLAUDE.md` import with TaskGraph's workflow guide. Pass `--no-claude` to skip the `CLAUDE.md` import. `init` does not install slash commands (step 3 does) and doesn't register the MCP server unless you pass `--mcp` (step 4).

<Warning>
Don't run `init` twice. It only re-adds the same files.
</Warning>

## 3. Install the plugin

The Claude Code plugin is the only way to get slash commands. It adds the `/taskgraph:` slash commands and two agents (`task-executor`, `task-checker`):

```txt
/plugin marketplace add stephennmiller/taskgraph-ai
/plugin install taskgraph@taskgraph
```

The plugin also adds two hooks and a `taskgraph` skill. In a project with a `.taskgraph/` folder, each Claude Code session (and each resume after compaction) starts with the output of [`taskgraph prime`](/capabilities/cli-viewing-commands#prime-a-coding-agent): the task in progress, what's ready next, and the workflow rules. Elsewhere the hook does nothing. The plugin states the oldest CLI it works with; when yours is older, or not installed, the hook tells Claude to ask you to run `npm install -g taskgraph-ai@latest` instead.

When Claude finishes a turn and a task is still in progress with no note from this session, the Stop hook reminds Claude once per session to log what it did with `taskgraph note`, or to close the task. The session starts when the session hook runs: it saves that time in a private folder in your temp folder (`$TMPDIR/taskgraph-<your user ID>/session-<session ID>`, readable only by you), and compacting the conversation keeps it. The `taskgraph` skill tells Claude to use TaskGraph when you ask what to do next or plan work in a project that has `.taskgraph/`.

Check that each step worked:

```bash
taskgraph doctor
```

It prints one line per check (Node, Claude Code and its sign-in, the project, the plugin and the MCP server) and the fix under each one that failed, and exits 1 if any did.

## 4. (Optional) Add the MCP server

The slash commands (from the plugin) and the CLI do everything without MCP. Add the server only if you want to drive TaskGraph in plain language:

```bash
claude mcp add taskgraph-ai --scope user \
  --env TASKGRAPH_TOOLS=standard \
  -- npx -y taskgraph-ai
```

Restart Claude Code and run `/mcp`. `taskgraph-ai` should show as connected. If you see `0 tools enabled`, restart Claude Code and confirm `npx -y taskgraph-ai` starts on its own in a terminal.

The equivalent `.mcp.json` entry is:

```json
{
  "mcpServers": {
    "taskgraph-ai": {
      "command": "npx",
      "args": ["-y", "taskgraph-ai"],
      "env": { "TASKGRAPH_TOOLS": "standard" }
    }
  }
}
```

## Staying up to date

Running `taskgraph` in a terminal checks npm for a newer version, at most once an hour, and tells you when one is out. When npm can't be reached within 3 seconds, the next check waits 10 minutes. The check does not install the update. Install it yourself:

```bash
taskgraph upgrade
```

`taskgraph upgrade` always asks npm, whatever an earlier check cached, and exits non-zero when npm can't be reached.

To install updates automatically, set `TASKGRAPH_AUTO_UPDATE=install`, or put this in `~/.taskgraph/auto-update.json` (your home directory, not a project's `.taskgraph/`):

```json
{ "autoUpdate": "install" }
```

TaskGraph never installs an update when input isn't a terminal, when `CI` is set, when the command prints JSON, or from `loop` and `loop --parallel`. Those runs set `TASKGRAPH_SKIP_AUTO_UPDATE=1` on every process they start. Set that yourself to skip the version check. If an install is already running, another one skips it instead of installing twice.
