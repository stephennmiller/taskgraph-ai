---
title: "Privacy"
description: "What TaskGraph and its Claude Code plugin do with your data: it stays on your machine"
---

TaskGraph is a local tool. It has no account, no server and no telemetry, and collects nothing about you or your project.

## What stays on your machine

- Tasks, config, reports and notes live in `.taskgraph/` in your project. TaskGraph never uploads them.
- The usage and cost summary printed after an AI command is computed locally and not sent anywhere.
- The Claude Code plugin's hooks run your installed `taskgraph` CLI and read only `.taskgraph/` in the project. They make no network calls.

## What leaves your machine

- **AI calls** go through your own Claude Code, to Anthropic, under your Claude account and [Anthropic's privacy policy](https://www.anthropic.com/legal/privacy). TaskGraph sends the task text and project context the command needs, and nothing else.
- **Update checks:** the CLI asks `registry.npmjs.org` for the latest version and fetches release notes from `raw.githubusercontent.com`. Set `TASKGRAPH_SKIP_AUTO_UPDATE=1` to turn this off.
- **Research:** the `research` skill and command search and fetch web pages for the question you ask.
