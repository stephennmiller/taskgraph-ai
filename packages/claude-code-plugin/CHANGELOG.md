## Unreleased

- `/taskgraph:go <prd-file>` runs `taskgraph go`: it plans a PRD into tasks and has Claude Code build them. It asks before it runs with permission prompts off; `sandbox` runs it in Docker.
- `/taskgraph:update-task` is now `/taskgraph:update`, the name of the CLI command it runs. There is no alias.
- Argument hints use one style: `<required>` and `[optional]`, lowercase with hyphens (`<task-id>`, `[status]`, `<prd-file>`).
- Needs `taskgraph` 0.63.18 or later, the first release with `go`.
