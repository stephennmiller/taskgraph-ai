Default to the latest Claude models. New projects now use Claude Sonnet 5.5 for the main and fallback roles, and Claude Fable 5.1, Opus 5.5, Sonnet 5.5 and Haiku 5.5 are available in `task-master models`. Older Claude 3, 3.5, 3.7 and Claude 4 dated models are hidden from the model picker, but existing configs that name them keep working.
